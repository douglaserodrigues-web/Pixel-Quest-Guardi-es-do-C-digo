# Pixel Quest: Guardiões do Código

Jogo de plataforma 2D feito com HTML, CSS e JavaScript puro.

## Como jogar
Abra `index.html` em um navegador moderno. Use as setas ou A/D para mover e Espaço, ↑ ou W para pular. Pressione P para pausar e R para reiniciar a fase.

## Arquivos
- `index.html` — jogo completo, incluindo estilos e JavaScript.
- `GDD.md` — documento de design do jogo, tecnologias, prompts de IA e plano de testes.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `README.md` e `GDD.md`.
3. Acesse **Settings → Pages**.
4. Em *Build and deployment*, escolha a publicação pela branch principal e pasta `/ (root)`.
5. Salve e aguarde o GitHub gerar o link público.
